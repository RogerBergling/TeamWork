TeamWork Link Opener

Open Jitsi meetings and Matrix/Element links in the TeamWork desktop application.

Managed by your organization. Settings marked as managed are supplied by enterprise policy and cannot be overridden.

Trusted Jitsi servers

One hostname per line, for example jitsi.example.com. Links on these servers are converted to teamwork://join links.

Matrix / Element

Element hostnames and matrix.to links can be opened with teamwork://matrix. The Element URL must also be configured in TeamWork.

Opening behavior

Automatic redirect is recommended for trusted company domains. Browsers may still ask once for permission to open TeamWork.

Test a link

Paste a Jitsi, matrix.to, or Element link to see how the extension will handle it.
